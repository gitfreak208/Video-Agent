# Tone

Declarative, consultant-grade, evidence over enthusiasm.

- If a sentence would sit in a McKinsey or Bain brief, it passes. If it reads like a launch tweet, rewrite it.
- Antier's view is phrased as a view. Projections are not outcomes.
- Every factual claim has a source (see the claims table in each video's `script.md`).
- No corporate enthusiasm. No unsourced superlatives. See `banned-words.txt`.
- No em dashes. Use a comma, a full stop, or a colon.

**Default audience:** financial-institution and fintech decision-makers, not retail crypto. Avoid jargon a bank audience would not use, or define it on first use.
