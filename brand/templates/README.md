# Template components

Shared Remotion components, reused across all videos (CLAUDE.md Section 9). Built during first-run setup (Section 11, step 4) — **not yet built; this pass is scaffold + config only.**

Each takes a `layout: "16x9" | "9x16"` prop and per-layout timing:

- `Intro`
- `Outro`
- `LowerThird`
- `Caption`
- `ChartFrame`
- `TitleCard`
- `FlowDiagram`

Changing a template later is a repo-level change: say so, and note which past videos would re-render differently.
